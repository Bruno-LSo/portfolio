Núcleo de dados

Pacote Python usado pelos demais projetos para abrir arquivos de dados. Se o arquivo está no disco, usa o do disco. Se não está, baixa a cópia guardada e confere que ela é idêntica ao original.

Como o arquivo é guardado

Funções

  • caminho(ref)Devolve um caminho local, do disco ou do cache.
  • ler(ref)O mesmo, já lido com pandas pela extensão.
  • guardar(arquivo)Envia e registra no catálogo, com os repositórios que leem o arquivo.
  • glob(padrão)Junta o que está no disco com o que está no catálogo.
  • existe(ref)Substitui os.path.exists para arquivos de dados.
  • listar(filtro)Consulta o catálogo.
  • credencial, segredo, preparar_env, preparar_arquivoRecriam .env e arquivos de chave a partir do cofre, sem guardar valor no repositório.

Segurança

  • Buckets privadosSem URL pública.
  • Catálogo fechadoRLS ligado e forçado, sem política. Só a chave de serviço lê e escreve.
  • Teste com chave públicaCatálogo, arquivos e segredos respondem bloqueado (401).
  • UsoSó em scripts locais. Nunca em página ou aplicativo no navegador.

Teste antes de apagar

A variável NUCLEO_DADOS_SEM_DISCO=1 faz o pacote ignorar o disco para tudo que está no catálogo. O projeto roda como se a pasta original já tivesse sido apagada.
